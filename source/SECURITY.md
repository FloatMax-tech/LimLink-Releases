# Security policy

Please report suspected vulnerabilities privately to **limlink@floatmax-tech.com**.

Do not open a public issue for a security problem before a fix is available. Include:

- LimLink version and platform
- Steps to reproduce
- Impact and affected files or protocol messages
- Relevant logs with personal data, file names, keys and tokens removed

Do not send private keys, signing certificates, passwords, verification codes, customer files or unredacted logs.

The most relevant areas are TLS 1.3 mutual authentication and SPKI pinning, device discovery, the pairing/binding control protocol, file consent, staging and atomic publication, and platform key storage.
