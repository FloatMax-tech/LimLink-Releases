LimLink 是局域网文件直传工具，不要求注册账号，文件不经过开发者服务器。苹果客户端当前支持单个文件，最大 5 GB。iPhone/iPad 需要 iOS/iPadOS 17 或更新版本，Mac 需要 macOS 14 或更新版本。

## 开始传输

1. 两台设备连接同一局域网，并在双方打开 LimLink。iPhone/iPad 传输时请保持应用在前台。
2. 在发送端选择文件或照片，再选择附近的接收设备。
3. 未绑定时在接收端核对发送方名称和文件信息，确认接收；双方有效绑定后自动接收。
4. 等待发送与接收结果，确认文件已保存，再决定是否删除源文件。

设备名称可以自定义，不能单凭名称判断对方身份。请仅向信任的设备发送文件。

## 绑定自己的设备

在支持绑定的双方版本中，打开本机身份/设置中的“绑定设备”，选择目标并点击绑定；对方确认一次后，双方以后互传可自动接收，不需要先发送文件或核对验证码。请确认是你认识的设备，因为名称可自行修改。绑定不会改变前台要求、文件大小限制和保存位置。

你可在“已绑定设备”中解绑，停止本机后续自动接收；对方离线时不保证立即清除其记录。身份密钥变化、关系只在一端完成或旧版不支持时会恢复逐次确认，必要时重新绑定。已经保存的文件不会被撤回，正在进行的传输可另外取消。

## 没有发现设备或传输中断

确认双方都允许了本地网络访问。系统设置中的 LimLink 权限或“隐私与安全性 → 本地网络”可用于管理该权限。若两个设备接入的是访客 Wi-Fi，路由器的设备隔离可能阻止相互发现。切回双方应用前台后重试；大文件还需确保接收位置有足够可用空间。

当前没有跨互联网链接下载、开发者云中转或关闭应用后的后台接收服务。不需要移动互联网连接即可在可互通的局域网内收发。

## 文件保存和删除

iPhone/iPad 默认将收到的文件保存在“文件 → 我的 iPhone/iPad → LimLink”。如果你另选了保存文件夹，请到所选位置查找。Mac 请查看应用显示的保存位置。

部分收发记录仅在当前应用会话中显示。重新启动后记录消失不代表文件已经删除。删除收到的文件可能将其移入系统废纸篓或“最近删除”；不支持该功能的位置可能直接删除。卸载应用不会清理你另存到外部文件夹的文件。

# LimLink Support

Developer: 周甫俊. Last updated: October 23, 2026.

LimLink transfers files directly between devices on the same local network. No account or developer-operated file relay is required. Apple clients support one file at a time, up to 5 GB. iPhone/iPad require iOS/iPadOS 17 or later; Mac requires macOS 14 or later.

## Transfer a file

Open LimLink on both devices on the same local network. Choose a file or photo on the sender and choose a nearby recipient. Unbound devices confirm each request; a current valid binding permits automatic reception. Keep both apps in the foreground, allow enough free storage, and verify the saved result before deleting the original. Device names are editable and do not prove a person's identity.

## Bind your devices

With compatible versions, open Bind Device in identity/settings, select the peer and press Bind. Only the other person confirms once; subsequent transfers can be received automatically in both directions. No file or comparison code is needed. Check that you recognize the device: names are editable. Binding does not remove foreground requirements, file limits or save-location rules.

Use Bound Devices to unbind and stop future automatic reception on this device. An offline peer's record may remain. Key changes, a relationship completed on only one side or an old unsupported client return to per-file consent; bind again if needed. Saved files are not recalled, and an active transfer can be cancelled separately.

## Discovery and interruptions

Check local-network permission for both apps in system settings. Guest-network or router client-isolation settings can prevent nearby devices from reaching each other. Return both apps to the foreground and retry. Internet download links, a developer cloud relay and receiving after the app is closed are not provided. Transfers work on a reachable local network without mobile Internet access.

## Find or delete received files

On iPhone/iPad, the default location is Files → On My iPhone/iPad → LimLink; otherwise use your selected folder. On Mac, check the save location shown by the app. Some history is session-only: losing a history entry does not delete the file. Deletion uses system Trash or Recently Deleted where supported; other locations may delete directly. Uninstalling the app does not remove files you saved outside its container.
