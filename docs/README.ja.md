## ダウンロード

公式インストーラーを準備中です。検証済みパッケージを Releases で公開します。

- [Android · APK](https://github.com/FloatMax-tech/LimLink-Releases/releases)
- [Windows · EXE](https://github.com/FloatMax-tech/LimLink-Releases/releases)

ファイルを選択 → 近くのデバイスを選択 → 相手が受信を承認。ペアリング済みデバイスはアプリの設定に従い自動受信します。

1ファイル最大 5 GB。同じ相互接続可能なローカルネットワークに接続し、アクセスを許可してください。LimLink アカウントは不要です。

## 更新

設定の「更新を確認」から説明を読み、確認後ブラウザーでダウンロードします。転送を完了してから、互換性のある公式署名付きインストーラーで上書き更新してください。データを保持するため、先にアンインストールしないでください。

## プライバシーとサポート

確認やダウンロード時に GitHub に接続し、IP アドレスと通常のリクエスト情報が処理される場合があります。ファイル、端末名、ペアリング情報は送信しません。このリポジトリには配布物、バージョン情報、説明のみを掲載し、アプリのソースコードは含めません。
