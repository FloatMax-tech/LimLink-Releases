## 下載

正式安裝套件準備中，驗證後會提供於 Releases。

- [Android · APK](https://github.com/FloatMax-tech/LimLink-Releases/releases)
- [Windows · EXE](https://github.com/FloatMax-tech/LimLink-Releases/releases)

選擇檔案 → 選擇附近裝置 → 對方確認接收。已綁定裝置依應用設定自動接收。

每個檔案最大 5 GB。裝置需連上可互通的區域網路，並允許本地網路存取。不需要 LimLink 帳號。

## 更新

在設定中點擊「檢查更新」，查看說明並確認後於瀏覽器下載。請先完成傳輸，再以官方相容簽名的安裝套件覆蓋升級；不要先解除安裝，以保留資料。
