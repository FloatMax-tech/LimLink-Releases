## Téléchargements et mises à jour

Les programmes d’installation sont en préparation. Terminez les transferts puis utilisez une signature compatible pour conserver les données.

| | Android | Windows |
| :--- | :--- | :--- |
| Chine : CN | [Android CN](https://limlink.floatmax-tech.com/download/android-cn) | [Windows CN](https://limlink.floatmax-tech.com/download/windows-cn) |
| International : WD | [Android WD](https://limlink.floatmax-tech.com/download/android) | [Windows WD](https://limlink.floatmax-tech.com/download/windows) |

CN ne recherche pas de mises à jour dans l’application. Le bouton ouvre la page officielle dans le navigateur.

WD consulte version.json sur le site officiel uniquement sur demande, puis ouvre les téléchargements dans le navigateur.

Transfert direct sur un réseau local accessible, jusqu’à 5 GB par fichier. Aucun compte requis.

WD transmet l’adresse IP et les données habituelles de requête, sans fichiers, noms des appareils ni associations. Pour CN, le navigateur gère l’accès au site. Ce dépôt contient uniquement des éléments de distribution ; le code source reste privé.
