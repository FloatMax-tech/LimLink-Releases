## Téléchargements

Les programmes d’installation officiels sont en préparation. Les fichiers vérifiés seront disponibles dans Releases.

- [Android · APK](https://github.com/FloatMax-tech/LimLink-Releases/releases)
- [Windows · EXE](https://github.com/FloatMax-tech/LimLink-Releases/releases)

Choisissez les fichiers, puis un appareil proche. Le destinataire accepte. Les appareils associés reçoivent automatiquement selon les réglages.

Maximum 5 GB par fichier. Les appareils doivent pouvoir communiquer sur le réseau local et autoriser cet accès. Aucun compte LimLink requis.

## Mises à jour

Dans les réglages, recherchez les mises à jour, consultez les notes et confirmez le téléchargement dans le navigateur. Terminez les transferts avant une mise à niveau avec un programme officiel à signature compatible. Ne désinstallez pas l’application pour conserver vos données.
