## 다운로드

공식 설치 파일을 준비 중입니다. 검증된 파일은 Releases에 게시됩니다.

- [Android · APK](https://github.com/FloatMax-tech/LimLink-Releases/releases)
- [Windows · EXE](https://github.com/FloatMax-tech/LimLink-Releases/releases)

파일 선택 → 주변 기기 선택 → 상대방이 수신 승인. 연결된 기기는 앱 설정에 따라 자동으로 수신합니다.

파일당 최대 5 GB. 서로 통신할 수 있는 로컬 네트워크에 연결하고 네트워크 접근을 허용하세요. LimLink 계정은 필요하지 않습니다.

## 업데이트

설정에서 업데이트 확인을 누르고 설명을 확인한 후 브라우저에서 다운로드하세요. 전송을 마친 뒤 호환되는 공식 서명의 설치 파일로 덮어 설치하세요. 데이터를 보존하려면 기존 앱을 먼저 삭제하지 마세요.
