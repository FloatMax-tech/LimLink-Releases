## Downloads

Official installers are being prepared. Verified packages will appear in Releases.

- [Android · APK](https://github.com/FloatMax-tech/LimLink-Releases/releases)
- [Windows · EXE](https://github.com/FloatMax-tech/LimLink-Releases/releases)

Choose files → select a nearby device → the recipient accepts. Paired devices receive automatically according to app settings.

Up to 5 GB per file. Devices must share a reachable local network and allow local-network access. No LimLink account is needed.

## Updates

Choose Check for updates in Settings, review the notes and confirm to download in your browser. Finish transfers first, then upgrade with an official, compatibly signed installer. Do not uninstall first if you want to preserve existing data.

## Privacy & support

Checking or downloading connects to GitHub, which may process your IP address and standard request information. Files, device names and pairing information are not sent. This repository contains installers, version metadata and documentation, not app source code.
